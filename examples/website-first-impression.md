# Website review: first impression

This illustrative scenario uses a fictional website and fictional observations. It does not report a user study.

## Reader task

A visitor should recognize that the site belongs to a small ceramics studio and find the path to browse available pieces.

## Example observations

- A patterned background, a large promotion, the site title, and four buttons have similar visual emphasis.
- The first viewport shows several product images but does not make the studio's offer or the main browsing action easy to identify.
- Price and availability appear only after a visitor opens a product page.

These observations describe the fictional example above. A real review should point to visible elements in the supplied screen or file.

## Evidence and inference

Tuch and colleagues (2012) studied aesthetic first impressions of company website screenshots. The [research note](../references/tuch.md) describes the methods and limits. Their experiments measured immediate aesthetic ratings and considered perceived visual complexity and how typical each page looked for a company website.

The study did not test this ceramics site. It did not measure whether visitors understand the offer, browse successfully, buy an item, or return later. Applying the study to this site's first viewport is an inference.

## Design hypothesis

Give the studio name, the type of work it offers, one representative product image, and the main browsing action a clear hierarchy. Keep price and availability visible when they help a visitor decide whether to open a product.

This proposal does not assume that a familiar layout is always better. The studio's audience and the task should guide the design.

## Check the proposal

1. Compare both versions at the same viewport size and with the same text and images.
2. Ask intended visitors what the studio offers and what they would do next. Record each answer separately.
3. If aesthetic impression matters, ask about it separately from comprehension and the browse task.
4. Run a browse task to check whether visitors can find an available piece and its price.

Use Tuch et al. to frame a question about first impressions. Do not use the paper alone to claim that a design improves usability or conversion. It does not establish a rule against gradients, centered text, or any specific component.
